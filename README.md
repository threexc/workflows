# workflows

A repository containing Forgejo workflows for my maintainer scripts.

The worfklows here should be broadly compatible with anything that is based on
Actions pipelines, but thus far I have only tested them on my home Forgejo
instance. If you have questions about why they're designed the way they are, or
how to set something similar up yourself, feel free to contact me at this
address:

tgamblin at ecocode dot ca

Please note that there are many features of Actions workflows which I haven't
taken the time to incorporate yet, and I am planning to do make many more
changes (for example, making my own custom Actions templates).
